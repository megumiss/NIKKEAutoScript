# NIKKEAutoScript

『勝利の女神：NIKKE』の自動デイリースクリプトです。PC／ARMエミュレーター／Android実機をサポートしています（**中国本土版を除く**）。[NIKKEAutoScript](https://github.com/takagisanmie/NIKKEAutoScript) からフォークされたプロジェクトです。

**🌐 公式サイト: [nkas.megumiss.top](https://nkas.megumiss.top)**

## 機能一覧

- **収穫**: 回収、殲滅、メールボックス
- **デイリー**: デイリーガチャ、デイリー、シーズンパス、相談、ショップ、スクラップショップ、花絮鑑賞会
- **前哨基地**: 派遣、解放、シンクロデバイス、リサイクルルーム、基地ストーリー
- **方舟**: シミュレーションルーム、オーバークロック、企業タワー、異常インターセプト、ルーキーアリーナ、特殊アリーナ、特殊アリーナ監視、チャンピオンアリーナ
- **期間限定作戦**: 協同戦闘、ソロレイド、同盟レイド
- **ストーリーイベント**: ストーリーイベント、自動マップ進行、自動掃討、ミニゲームデイリー、ショップ購入
- **地表**: 地表デイリー
- **Blablalink**: デイリーミッション、CDK自動交換、ポイント交換、Cookie自動更新
- **無料ギフト**: STEPUPギフト、デイリーギフト、ウィークリーギフト、マンスリーギフト
- **データチャート**: アイテム統計、インターセプト統計
- **ツール**: 自動タワー、半自動クリック（半自動メインストーリー）、ハイライト閲覧、CDK交換、画面回転、Hosts変更、イベントカウントダウン
- **その他**: PCクライアント／ARMエミュレーター対応、PCマルチモニター対応；タスク自動起動、ホットキーカスタム；自動更新・定期更新；複数インスタンス・順次実行；Dockerデプロイ；通知
