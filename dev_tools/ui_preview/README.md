# NKAS UI 重构预览

静态原型（假数据），用于在正式改造前审查新 UI 的框架、布局与操作逻辑。

- `preview.html`：交互原型（当前 v4）
- `PLAN.md`：**实施计划**（文件/类/方法级的改造清单与阶段验收）
- `shoot.js`：截图脚本，`shots/`：各页面截图

## 查看方式

直接用浏览器打开 `preview.html`（无外部依赖，可离线）。左侧导航切换页面，右上角「方案说明」内嵌完整设计说明。

重新生成截图（复用 `webapp/node_modules` 的 playwright）：

```powershell
node dev_tools/ui_preview/shoot.js
```

截图输出到 `shots/`。

## 现状分析（page_refine 分支之前的问题）

当前 UI 为 pywebio 服务端渲染（`module/webui/app.py`），此前的「ui调整」提交只改了 CSS 变量与少量弹窗交互，布局与操作逻辑未动：

- **交互模型脆弱**：每次点击都是 Python 回调 → 整片 scope 清空重绘 + `run_js` 拼 jQuery 字符串；滚动位置、表单焦点、页面状态随重绘丢失（`set_aside`/`_redraw_aside_status` 还需额外的锁防竞态）。
- **层级过深**：实例 → 折叠菜单组（12 组）→ 任务（50 个）→ 分组锚点 → 字段（447 个），无搜索，找一个选项要点 4~5 层。
- **首屏无价值**：打开面板默认落在语言/捐赠页（`show()`），最高频的调度总览与日志要再点两层。
- **状态失联**：运行状态与日志只在对应页面轮询可见，切页即断；Electron 客户端（`webapp/`）只是 iframe 套壳（`packages/renderer/src/components/NKAS.vue` 仅 `<iframe :src="webuiUrl">`）。

## 提案概要

- **后端**：保留 Python，将 `module/webui` 演进为 REST + WebSocket（日志/状态推送），基于 Starlette 原生路由、不新增 Python 包。进程管理（`process_manager.py`）、配置读写与校验（`NikkeConfig`、`args.json`）全部复用。
- **前端**：Vue 3 + Vite SPA（`webui/`，naive-ui + pinia + echarts，构建产物 `dist/` 提交入库）。表单由 `args.json` + i18n 驱动的通用渲染器生成，覆盖全部 447 个字段。
- **客户端**：Electron 壳零改动；旧客户端 iframe 加载 `/`，发布后 302 到新 SPA。UI 永远由后端下发，客户端不参与 UI 生命周期。
- **布局/逻辑**（v4，按审查反馈调整）：
  - 入口按实例数自适应：单实例启动直接进入该实例调度总览，多实例才落全局总览；
  - 全局总览 = 运行统计 + 实例卡片墙 + 快捷启停 + 全局操作；
  - 任务配置两级直达：点实例后任务栏常驻左侧，任务栏本身为**二级折叠**（分组可收起，默认展开含启用/运行任务的组，收起时显示启用数徽标），带即时筛选框（命中组自动展开）；
  - 工具任务（自动爬塔、半自动点击等）归入实例任务栏底部「工具」组，页面 = 参数 + 启动/停止 + 实时日志，与普通任务同级；
  - 任务页 = 页头（启用开关 + 立即运行）+ 调度器卡（默认折叠为摘要行）+ 参数分组卡（宽屏双列填满）+ 右侧锚点，即改即存；成功/失败间隔、服务器刷新时间为内部字段不展示；
  - 调度总览左列（调度器 + 队列）固定 320~400px，剩余宽度全给日志；
  - 表单控件统一规格：文本/下拉 38px × 280px，数字输入带单位后缀，日期时间带图标，日志时间戳与等级 chip 定宽对齐；
  - 字体系统：正文 15px 起，Segoe UI Variable / Microsoft YaHei UI / PingFang SC 字体栈，日志用 Cascadia Code 等宽；
  - 状态常驻：侧边栏实例状态点/任务徽标 + 顶栏调度状态 pill；
  - 更新器/远程访问/语言/主题归入全局「设置 / 更新」，捐赠与帮助归入「关于」。
- **分发与切换**：构建产物 `webui/dist/` 入库随 git 更新分发（Updater/CI 分发流程/Electron 均不改，CI 仅加构建一致性校验）；发布即切换（`/` 302 → `/app/`），不做双 UI 过渡版本，配置格式不变，用户零迁移成本。
