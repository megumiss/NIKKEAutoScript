v4 调整（按审查反馈）

  • 字体系统重做：全局字号上调（正文 15px、导航 14.5px、表单 14.5px、辅助文字 ≥12.5px），字体栈改为 Segoe UI Variable / Microsoft YaHei UI / PingFang SC（UI 优化字形），日志用 Cascadia Code 等宽字体。
  • 调度器组默认折叠：任务页的「调度器」卡片收起为一行摘要（启用状态 + 下次执行时间），点击展开；成功间隔 / 失败间隔 / 服务器刷新时间为自动化内部字段，不再对用户展示。
  • 任务页双列填满：分组卡片改为 auto-fit minmax(440px, 1fr) 网格，宽屏下多张卡片并排，右侧不再整片空白。
  • 入口自适应：仅 1 个实例时启动直接进入该实例的调度总览（全局总览仍在侧边栏可点）；多实例时才落在全局总览。全局总览横幅上有「模拟单实例入口」按钮可现场演示。

框架

  • 后端：Python FastAPI REST + WebSocket（日志/状态推送），复用现有进程管理与 args.json 配置体系。
  • 前端：Vue 3 + Vite SPA + Naive UI，表单由 args.json + i18n 驱动的通用渲染器生成（覆盖全部 50 任务 / 447 字段）；哪些字段对用户展示由 args.json 的 display 标记控制，间隔类字段标 hide。
  • 客户端：Electron 壳保留，渲染层从 iframe 换成 SPA；浏览器直连同样可用。

操作逻辑

  • 入口：单实例 → 实例调度总览；多实例 → 全局总览（运行统计 + 实例卡片墙 + 全局启停）。
  • 实例 = 工作台：任务栏常驻（两级折叠、状态点：绿=启用，旋转=运行中），点任务两级直达配置。
  • 任务页 = 页头（启用开关 + 立即运行）+ 可折叠调度器卡 + 参数分组卡（双列）+ 右侧锚点；即改即存。
  • 工具任务页 = 页头（启动/停止）+ 参数卡 + 实时日志卡，与普通任务同级。
