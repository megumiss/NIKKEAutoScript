# 自动主线模块

正式入口为 `module.campaign.campaign.Campaign`。地图、视觉与移动实现在本包中共享，
正式任务使用生产 Device 会话，独立实验命令只提供 CLI 和窗口适配。

## 目录职责

| 位置 | 职责 |
| --- | --- |
| `campaign.py` | 资源与游戏窗口准备、上层场景及章节会话调度、正式任务入口 |
| `noncombat.py`、`scene_session.py` | 章节无关的剧情、换章、主页及方舟接管；独立页面输入与共享战斗按钮 |
| `execution.py`、`session.py`、`window.py` | 有限执行与战斗接管、生产 Device 会话、停止与输入护栏 |
| `goals.py`、`subgoals.py`、`scouting.py`、`run_state.py` | 目标选择、解封与电梯子目标、拖展开地图侦察敌人的路程排序、跨帧运行状态 |
| `report.py` | 日志用词与行格式：内部标识翻成中文、坐标与状态摘要的统一写法 |
| `trace.py` | 每次正式执行的截图归档、事件时间线与离线回放页 |
| `timing.py` | 分阶段耗时（单调时钟秒表），日志里的所有「耗时 x.xxs」都从这里取 |
| `map/` | 标注校验、章节资源定位与名称映射、静态道路、连通分区、道路编辑与坐标变换 |
| `vision/` | 小地图配准、YOLO 感知、箭头／离屏标记、场景地面配准、战斗接管状态识别；模型和模板也在此处 |
| `navigation/` | 共享 A*、切开路网、移动与镜头闭环、电梯、停稳反馈、共同会话接口 |
| `tools/` | 命令行实验、校验与回放、实验设置及采集器窗口；生产入口不导入此子包 |

正式会话和实验会话都复用 `navigation.movement.navigate` 与
`navigation.session.NavigationSession`。模板在 `vision/assets/`；ONNX 与模型元数据由资源仓库同步到
`data/resources/models/campaign/`，不随主仓库分发。

## 启动与场景接管

- 仅支持 PC 客户端，客户区按 `1776×999` 处理；资源与运行依赖在任务开始时检查。
  具体章节限制和使用风险见任务页注意事项。
- 可从野外、剧情、章节列表、主页、方舟、前哨基地和战斗相关页面启动。上层
  `CampaignSceneController` 处理页面，章节与难度连续三帧一致后建立章节会话。
- 页面离开野外时交回上层，不在章节导航中推进换章或按旧坐标回正。只点击可靠匹配的按钮，
  未知页面有界等待，不遍历所有菜单或盲点固定坐标。
- 同章返回保留敌人、机关、光幕、EX 避让及累计失败历史，重新取得定位；章节、难度或地图
  版本改变时重建状态。MISSION CLEAR 后必须确认预期下一章和原难度，不能接受旧野外瞬态。

## 目标规划与设施

- 敌人类型以可靠小地图检测为准，历史位置只用于侦察；漏检不等于已清除。
  普通敌人优先于 Boss，EX 不作为战斗目标。主线菱形只帮助切换视野和确认身份，不直接作为地面落点。
- 已绑定目标使用实际道路排序和规划。跨区移动必须使用标注的有向电梯连接，不能把全章连通
  或屏幕距离当作步行可达。可见近敌也须两帧确认和当前切开路网的 A* 校验。
- 光幕位置以标注为准，按对象独立确认状态；遮挡、失去关联和离屏不能作为解除证据。
  机关只直点当前唯一关联且位于安全区的未开启目标，确认触发后解除唯一对应封锁并重新扫描。
  机关确认解除在本次会话内为终态，普通观测不得将其复活；其他清除仍允许后续实际检出纠正。
- 电梯以入口建立步行基准；连续两帧确认进入出口区域后才记录传送，再执行出口区域扫描。
  到达出口附近、发送点击或一次位置跳变都不能代替确认。
- 实际关联的 EX 弹窗证据可纠正同编号类型，不能改写相邻目标或宣告战斗清除；关闭后沿安全
  路线退出和绕行，保留原路程目标与失败历史。

## 观测、扫描与恢复

- 开局和定位恢复完成后必须取得可信小队位置，居中并完成有界十字扫描；至少一屏可信才放行。
  中断保留待扫描标记，扫描失败不清空恢复额度。普通战后按需侦察，不强制完整扫描。
- 沿当前目标前置道路侦察，一拍共用八屏额度；改选目标后只用剩余额度续查。未确认焦点及
  失败记录保留，不能把已覆盖粗格当作敌人复核，也不能反复扫描清零累计失败。
- 配准须同时满足完整投影、候选质量和小队道路归属。镜头中心可以在底图外，小队坐标不可以。
  仅移动镜头时可保留未移动的小队坐标，不能用它预测场景脚点。
- 收起展开地图后重新截图并识别当前场景。仅可复用小队坐标时返回 `reused`，不附带旧展开
  矩阵、敌人或覆盖，不伪装成当前帧的 `accepted`。
- 战斗结束或位置冲突时清除旧小队、导航报告和镜头参考。恢复必须取得本次实测，不能靠旧缓存
  续期；严格回正后的有效位置确认可供继续规划，但不补造紧凑帧的视觉证据。
- 地图开合和纯视野校正不解释为小队位移。首次远目标拖动需建立展开视野与紧凑注视点的
  对应关系；校正失败不发送后续移动。

## 战斗与章节结束

- 准备、加载、战斗、结算和返回野外分别处理，加载中的野外瞬态不代表接管结束。
  战斗结果与页面返回分开确认，只有可靠胜利才清除对应敌人。
- 快速战斗优先；不可用时进入普通战斗。自动射击与自动爆发分别确认关闭，连续两帧可靠
  关闭才点击，每个开关每场最多一次；未知状态和非战斗页面不授予点击许可。
- 战败只重打同一目标，结算屏停留不重复消耗重试次数。战败重试耗尽直接交人工，不返回主页重启。
- Boss 胜利后识别 MISSION CLEAR，交上层处理章节结束和切换，不沿用战前定位进入下一章。

## 实际操作统计与路线无进展保护

输入成功发送后才统计操作；截图、定位、状态检查和停稳采样不计操作。任务不按累计操作总数
截断正常推进，各阶段分别受次数或超时限制。

真实移动后的可靠定位按冻结目标和道路比较历史最优剩余路程；EX 退出阶段使用冻结退出路点。
重规划、标记微调、地图开合和 EX 中断不重置失败。连续三次无可靠路线进展停止，邻近光幕推定
只在唯一标注且真实改变路网时允许当前目标重建基准，同一标注每章一次。

业务异常结束时，每次任务最多返回主页并重新进入一次；返回前清空本章运行状态，主页重进同章也重新建立
地图标记与失败历史。用户停止、窗口或驱动异常、战败重试耗尽不追加恢复输入。失焦暂停并尝试恢复前台，
等待期间仍检查停止与窗口。

## 推图设置

- `AutoMainStory.CampaignSettings.ResourceRepository`：当前实例的地图资源同步仓库，支持预设选择和自定义地址；
  地址保存到 `config/<实例名>.json`，不使用部署配置。同步后的 `data/resources/` 仍由所有实例共用，
  同时只允许一个资源同步任务；Mirror酱继续使用部署页的更新源与 CDK，不使用仓库地址。
- `CampaignSettings.MissedEnemyScan`：Boss 前遗漏补扫，默认关闭；不影响开局／恢复扫描、
  普通敌人处理、按需侦察和安全检查。开启后检查章节敌人进度并补扫遗漏区域。
- `CampaignSettings.DebugMode`：调试留档，默认关闭；实时预览和正常任务不依赖该开关。

设置按任务保存；仓库地址在下次手动同步或版本检查时生效，其余设置在下次启动任务时生效。

## 运行证据与离线回放

关闭调试时不新增留档、不更新 `last_field.png`、不清理已有归档。开启后按会话保存：

```text
log/campaign/scenes/runs/<运行目录>/                  上层场景会话
log/campaign/<难度>_<章节>/runs/<运行目录>/           章节会话
  run.json             运行身份与客户区信息
  events.jsonl         截图、输入、观测、决策及停止事件
  frames/              客户区 JPEG 与原始小地图 PNG
  summary.json         完成状态、错误及操作统计
  last_field.png       最后实际采集的无损画面
  events.js            正常收尾生成的回放数据
  index.html           正常收尾后的离线回放入口
```

调试开启时也更新章节目录的 `last_field.png`，保留最新画面的诊断入口。

普通帧限频，输入前后及关键事件强制留帧，全部复用业务截图，不为留证增加游戏输入。
`input_sent` 只表示输入调用返回，不表示点击生效；`frame_ref` 指向实际已保存帧。
正常收尾生成回放所需数据；强制结束时可能只保留 JSONL 和已有图片。

每章保留最近十次已完成归档和全部未完成归档。归档写入失败只告警并停用归档，不改变输入闸门。
日志记录决策、阶段耗时、目标依据和失败原因；同一画面不重复输出无变化的状态明细。

## 页面注意事项文案

文案位于 `notice/zh-CN.md`、`notice/en-US.md`、`notice/ja-JP.md`。标题和摘要可省略，
正文支持 Markdown；原始 HTML 和图片禁用，未知语言或缺失翻译回退中文。
有效文案仍缺失或完全空白时隐藏提示，不影响任务。
后端 `/api/campaign/notice` 每次重新读盘，修改文案后刷新页面即可，无需前端构建。
