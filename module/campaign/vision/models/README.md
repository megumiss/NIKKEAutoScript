## Boss 业务接入

- 快照及运行记忆保留 `kind='boss'`。Boss 与普通敌人都参与可达待清目标选择，按道路距离排序；
  机关优先、主线目的地、沿途清敌和光幕／电梯约束保持不变，不强制优先攻击远处 Boss。
- 通过主线菱形两帧验证时保留 Boss 类型。实际执行仍为 `kind='enemy'`，以 `enemy_kind='boss'`
  贯穿导航、脚圈匹配、点击复核和战斗归属。附近普通敌人及 EX 不可替代 Boss 标记。
- 普通／Boss／EX 相邻时同帧不覆盖同一记忆编号。EX 仅展示和记忆，不自动选择或接管。
- Boss 胜利只清除对应目标；战后重核章节及难度，变化或无法确认时停止，旧地图不能跨章继续使用。
- 地图以星形轮廓显示 Boss，并在图例、敌人列表、执行目标及路程目标显示 Boss 标签。

## 游戏内验收路径

中文 Windows `1776×999` 客户区，在普通 38、困难 7、困难 40 章 Boss 附近运行主线：

1. 紧凑／展开面板切换并覆盖旋转、靠边，核对完整 Boss 显示为独立类型、截边时不猜测导航坐标。
2. Boss 与普通敌人、EX 相邻时，核对路程选择和最终点击始终对应原类型；EX 弹窗只关闭并停止。
3. 核对沿途普通敌人先处理、Boss 冷却不会反复点击、Boss 战斗胜利只清除自身编号。
4. 胜利后核对章节及难度；清章或换章时不复用旧地图。
5. 回归光幕居中／立柱辅助、电梯终点和脚圈拒绝条件，保留输入前后截图与回放事件。

运行时只需 ONNX Runtime，无须 PyTorch 或 Ultralytics；可选依赖见 `requirements-yolo.txt`。
