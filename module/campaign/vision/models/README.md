# 战役识别 v10：场景、缩略小地图、展开小地图

本模型包采用固定的 B 方案：**场景整图一次 + 当前小地图一次**。共有三个专用模型，
缩略与展开按本帧状态互斥选择，不是每帧运行三个模型。关闭或无法确认小地图时不运行地图模型。

## 模型契约

| 角色 | 文件 | 类别 | 原始输入 | 网络输入 NCHW |
| --- | --- | ---: | --- | --- |
| 场景 | `scene.onnx` / `scene.json` | 9 | 1776×999 客户区 BGR 图 | 1×3×1024×1792 |
| 缩略地图 | `compact.onnx` / `compact.json` | 4 | 218×211 面板 | 1×3×640×640 |
| 展开地图 | `expanded.onnx` / `expanded.json` | 4 | 486×462 面板 | 1×3×640×640 |

`bundle.json` 绑定同一版本的三个角色；模型与元数据必须成套分发。加载时核对角色、类别顺序、
输入输出尺寸、预处理约定和模型 SHA-256。旧十三类 `campaign.onnx` 不再作为运行入口或回退模型。

场景模型统一识别箭头、收集提示、机关开/关、电梯起/终点、光幕、立柱及敌人脚圈。
两种地图模型都识别普通敌人、EX、小队圆环和 Boss，但分别训练、分别加载权重。

全部模型为 YOLO11n、FP32 ONNX，保持 RGB `/255`、等比缩放、居中填充 114 和分类别 NMS（IoU 0.45）。
当前运行端使用 ONNX Runtime CPU 后端，算子线程默认 4；应用运行不依赖 PyTorch 或训练 GPU。

## 取图、共享与安全边界

- 每次完整观测冻结一份截图，同一帧共用面板裁剪与原始推理结果，不再保留八块网格和六块遮罩切片。
- 缩略面板先将客户区归一化到 1920×1080，再裁 `(25,96,243,307)`；
  展开面板直接裁客户区 `(644,280,1130,742)`，不进行二次缩放。
- 模式判定仍使用本帧控件和地图外观；切换、关闭和未知状态不沿用上次模式。
- 同帧按类别筛选、箭头定位和低阈值光幕复核共享原始输出；阈值和解码结果不跨调用方混用。
- 每个角色最多缓存四份原始输出；不同观测作用域不复用上一帧结果。异常通知全部同键等待者并允许重试。
- 保留小地图截边/控件排除、圆环拟合、箭头精定位、脚圈可点击区域及导航身份检查。
- 模型包更新后需要重启任务。首次加载会锁定包指纹，新角色不能与进程内旧版本混用。

## 阈值

场景电梯起点和脚圈为 **0.7**，已激活机关为 **0.65**，立柱为 **0.45**，其余场景类别为 **0.5**。
两种小地图的四类阈值均为 **0.5**。关联光幕的消失否决复核仍单独使用 **0.2**，不改变正常检测阈值。

阈值标定只使用训练与验证回归，历史测试不参与选择。元数据记录源检查点、数据清单和标定报告摘要。

## 训练与离线验证

- 三份数据为 638 张完整场景、44 张缩略面板和 2152 张展开面板；原图或完整面板均经过像素摘要核对。
  83 张无法恢复完整原图的旧场景没有用切片冒充整图。数据保留类别监督范围，未标注类别不是背景。
- 初始化按类别名称映射 v9-boss 权重，不复制前 N 个类别。场景与展开训练 30 轮，缩略训练 40 轮。
- 274 张场景、44 张缩略、103 张展开图片的已标注类别，以 IoU≥0.5 和正式边界规则回归，
  与旧动态切片流程相比没有新增逐帧误检或漏检。
- 完整观测回放 65 张真实留档、两版各三轮，共 390 次：新版本每帧实际推理 2 次，
  定位状态及小队坐标与旧版一致。检测框和置信度并非逐位相同，不把旧模型预测当作真值。
- 另外复核六个未参与训练或阈值标定的 Boss 案例：三个完整展开标记进入观测；
  截边、缩略控件邻近标记及按钮误候选被拒绝。复核为 Codex 视觉复核，不是用户逐框确认。

这些是按标注范围的历史回归和小规模新批次检查，部分数据已被源权重见过。
**不能据此宣称未见章节的独立准确率，也没有独立的缩略地图可导航 Boss 正样本泛化结论。**

本轮同机对照中，完整调用链内检测均值约 171→135 ms；普通观测检测约 242→138 ms，
已知小队位置的镜头侦察约 150→134 ms。完整观测约 642→602 ms，仍受地图配准等非检测计算限制。
以上先取逐帧三轮中位数，再按样本分组平均；不代表整场推图耗时比例。

## 验证范围与复现

运行依赖见根目录 `requirements-yolo.txt`。训练工程位于本机 `E:/CodexData/NIKKEAutoScript/yolo`，
三模型使用独立的 `*_specialists.py` 训练、检查、导出、预测和回归入口，旧单模型入口不处理本模型包。

离线回放需覆盖中文 Windows 1776×999 客户区的缩略、展开、关闭、模式过渡、镜头侦察及恢复居中路径。
本轮按用户要求**未进行实机验收、未发送任何游戏输入**。后续如进行实机验收，应覆盖：

1. 缩略/展开切换，确认每帧只使用对应地图模型，控件附近和截边目标不用于导航。
2. 普通/EX/Boss 相邻时保持目标类型，EX 弹窗不进入自动战斗。
3. 光幕与立柱关联、机关状态、电梯起终点及脚圈点击前复核。
4. 镜头回正、战斗返回和换章后重新采样，不复用旧帧或旧地图坐标。
