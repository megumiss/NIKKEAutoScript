- 应用阈值：敌人脚圈 **0.7**，电梯起点 **0.7**，其他类别保持 **0.5**。脚圈与小地图敌人阈值不能混用。

  应用元数据仅调整脚圈阈值及接入状态，`release_decision` 保留导出时的历史发布记录。

## 取图与职责

| 类别 | 取图方式 | 说明 |
| --- | --- | --- |
| 场景箭头、收集提示 | 遮罩切片，6 片 640² | 沿用既有精定位流程 |
| 小地图圆环、普通／EX 敌人 | 小地图面板裁剪 | 展开或紧凑面板由调用方裁好，letterbox 后推理 |
| 机关、电梯、屏障、敌人脚圈 | 全画面网格，8 片 640² | X=0/384/768/1136，Y=0/359，逐片及全局分类 NMS，IoU 0.45 |

切片内部边界做 2px 截断保护。画面边缘的检测仍可展示，但脚圈辅助点击另行排除真实边缘截断和固定 HUD。

`objects.detect_objects` 将脚圈描述为 `kind='enemy_ring'`、`space='client'`。脚圈不区分普通和 EX，
不直接并入敌人记忆。`vision/enemy_ring.py` 只在普通敌人导航的两次可信观测间进行场景跟踪和运动匹配，
明确对应原目标后才返回脚圈中心；不使用大小地图的历史换算，不改变原目标或战斗归属。
具体拒绝条件见[自动推图流程](../../../../doc/campaign-auto-flow.md)。

## 使用与实机验收

模型首次检测时加载并复用，不需要 PyTorch 或 Ultralytics；可选依赖安装：

```powershell
.venv\Scripts\python.exe -m pip install -r requirements-yolo.txt
```

更新模型后重启加载模型的进程。验收先在中文 `1776×999` 客户区进入第 38 章多敌人路段，运行主线：

1. 保留目标选择、拖动前后帧、脚圈匹配日志及最终战斗弹窗，确认直点始终对应原普通敌人。
2. 验证脚圈出现但匹配不明确时继续原有拖动，已能正常点击时不额外拖动凑两帧。
3. 验证直点未触发后不反复吸附到同一脚圈，附近五个试点和原有操作预算不变。
4. 覆盖普通／EX 相邻、多个脚圈密集、遮挡、刚入屏、弱纹理、换章及不同拖动方向。

旧五类回放仍使用 `dev_tools/campaign/vision/evaluate.py`；训练、导出和 PyTorch/ONNX 对照在独立训练项目完成。
