# 地图标注工具

入口：[dev_tools/map_annotator.py](../dev_tools/map_annotator.py)。这是独立的本地浏览器工具，不启动游戏控制，不需要管理员权限。依赖 Python 3.9+ 和项目已有的 Pillow，不需要额外安装前端依赖或构建 SPA。

从 Wiki 批量下载普通／困难收集物并配准到共享底图，参见 [Wiki 批量导入与地图补采](wiki-collectibles-batch.md)。导入后仍可用本工具人工复核和编辑。

## 启动

在仓库目录、已安装项目依赖的 Python 环境中运行：

```powershell
python dev_tools/map_annotator.py
```

默认递归查找 `data/chapter_maps/current/` 下的地图包，与采集和 Wiki 导入共用目录，自动打开浏览器。网页只监听本机 `127.0.0.1:8766`。终端按 Ctrl+C 关闭服务。

指定单张地图或其他集合目录：

```powershell
python dev_tools/map_annotator.py --map data/chapter_maps/current/chapter_38
python dev_tools/map_annotator.py --root data/chapter_maps/current
```

`--map` 指向包含 `map.png` 和 `map.json` 的目录；未指定 `--root` 时，同级地图包也会进入下拉列表。`--root` 和 `--map` 一起使用时，后者必须在前者目录内。`--port 0` 可自动选择可用端口，`--no-open` 可关闭自动打开浏览器。

## 标注流程

1. 在上方选择地图包。需要核对道路时，将左侧图层切换为“实拍参考图”；两张图共用同一套标注坐标。
2. 在左侧选择五种标注类型之一：**普通收集品、困难收集品、地面机关、地面电梯、电梯传送关系**。前四种默认单击创建点，也可切换折线、多边形或矩形；名称、颜色可自行修改，名称不决定已分类标注的类型。
3. 通过画布上方的“普通／困难／全部”切换收集品显示，画布和对象列表同步筛选，机关、电梯及它们的传送关系共用。默认只显示普通收集品；切换普通或困难时，当前收集品绘制类型也随之切换。选择另一难度的收集品类型会切换到对应视图；“全部”视图可同时查看两种。切换不会修改已保存数据，保存始终包含被隐藏的标注。未完成绘制时先完成或按 Esc 取消，再切换。
4. 在图上绘制，随后用“选择”工具选中对象。拖动对象移动位置，拖动白色顶点修改形状；右侧可精确输入坐标、编辑类型、名称与备注、插入或删除顶点。点、折线、多边形分别至少保留 1、2、3 个不同顶点。
5. 先标注两部“地面电梯”，再选择“电梯传送关系”，依次点击起点电梯和目标电梯。勾选“新传送为单向”后，箭头由第一次点击的电梯指向第二部电梯；未勾选则为双向。已有关系也可在属性里修改方向。收集品、机关不能作为传送端点；已有传送关系的电梯需先删除关系才能改成其他类型。
6. 点击保存或按 Ctrl+S，将标注写入当前地图目录的 `annotations.json`。刷新或重新打开地图会加载已保存内容。右侧“文件与副本”可下载当前 JSON，或重新读取磁盘文件。这些标注不会自动触发导航或战斗逻辑。

| 工具 | 操作 | 快捷键 |
| --- | --- | --- |
| 选择 | 单击选中；拖动对象 / 白色顶点 | V |
| 平移 | 按住鼠标拖动；任何工具下也可按住空格拖动或使用鼠标中键 | H |
| 点 | 单击创建 | P |
| 折线 | 连续单击添加顶点，双击或 Enter 完成 | L |
| 多边形 | 至少三个顶点，双击或 Enter 闭合 | G |
| 矩形 | 从一个角拖到对角 | R |
| 电梯传送 | 依次点击起点电梯、目标电梯，自动选择电梯传送关系类型 | C |

滚轮以鼠标位置为中心缩放；“1:1”恢复原图比例，“适应窗口”显示全图。绘制时 Backspace 撤回最后一个顶点、Esc 取消本次绘制。Ctrl+Z 撤销、Ctrl+Shift+Z 或 Ctrl+Y 重做；文本输入框内保留原生文本撤销。Delete 删除选中标注，删除对象时同步删除相关连接，可撤销恢复。

## 文件与坐标

- 坐标始终为原图像素：左上角 `(0, 0)`，X 向右，Y 向下。缩放、平移和切换参考图不改变保存坐标；小数保留到 0.1px，这只是记录分辨率，不代表地图的实际定位精度。
- 点、折线、多边形保存为 `point` / `polyline` / `polygon`；矩形保存为四顶点 `polygon`，之后也可自由调整形状。`category` 保存标注类型：`normal_collectible`、`hard_collectible`、`ground_mechanism`、`ground_elevator`、`elevator_connection`。收集品同时写入 `difficulty: normal/hard`。`label` 是可编辑名称，`color` 为 `#RRGGBB`，`note` 是备注。传送关系沿用连接的 `id` / `from` / `to` / `directed` 格式，端点必须是不同的地面电梯。
- 兼容没有 `category` 的旧标注：优先使用已有 `difficulty` 或 `source.difficulty` 识别收集品，也可识别“普通收集品／普通收集物”“困难收集品／困难收集物”及“地面机关”“地面电梯”标签（可带空格分隔的后缀）。无法判断的旧标注保持可见，可在右侧手动指定类型。读取和筛选不迁移文件；手动改类型会更新 `category` 和收集品 `difficulty`，保留 Wiki `source` 来源记录。旧的普通连接仍可编辑，转换为电梯传送时会校验端点类型。
- 保存只更新 `annotations.json`，不修改底图、参考图或投影。底图尺寸、SHA-256 和标注绑定必须一致，参考图也必须与底图同尺寸。
- 每次覆盖前，将原标注备份到同目录 `.annotation_backups/`，再通过临时文件原子替换。恢复备份时先保留当前副本，再将选中的备份复制为 `annotations.json` 并重新加载。
- 未保存修改在离开网页或切换地图时会提示。若其他窗口或程序已经修改标注，保存会拒绝覆盖；先下载当前副本，再重新加载并比较。下载副本不等于保存到地图包。
- 数据目录受 Git 忽略，地图与人工标注不会因此自动进入版本库；需要时另行备份地图包。

## 验证

后端测试覆盖类型与难度一致性、电梯端点校验、几何与坐标校验、哈希绑定、连接完整性、原子写入失败、备份及并发冲突。浏览器回归覆盖五种类型、普通／困难筛选、旧 Wiki 数据兼容、传送关系及编辑撤销流程，使用独立临时地图包，不写入实际采集地图：

```powershell
python -m unittest tests.test_map_annotator -v
node tests/map_annotator_browser.cjs python
```

浏览器回归复用 `webui/node_modules/playwright`，需要该目录的开发依赖和 Playwright Chromium 已就绪；它们仅用于验证，不是标注工具运行依赖。第二个命令中的 `python` 可替换为项目虚拟环境解释器的绝对路径。可在末尾追加截图输出路径。
