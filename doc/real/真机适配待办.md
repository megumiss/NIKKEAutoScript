- 连接失败不再尝试拉起模拟器。

## 真机使用硬性前提

- `wm size 720x1280` 必须生效——它是所有模板坐标与触控坐标的基础，不生效则截图硬校验直接拦截，这是设计意图而非 bug。
- 分辨率切换会杀掉前台游戏进程，且**无法绕过**（2026-08-26 实测，nubia Z50 Ultra）：游戏在前台时 `wm size` 立即杀进程；先 HOME 退后台再改，进程当场存活，但切回前台时 Activity 按新配置重建、进程照样冷启动（pid 变更）。所以"停止实例恢复分辨率导致游戏重载"是系统行为，不要加"先退后台再恢复"之类的规避逻辑，没有收益。
- 屏幕必须常亮（开发者选项"保持唤醒"），锁屏/AOD 下截图黑屏或停在锁屏，NKAS 不会解锁系统锁屏。
- 色差问题仍存在，但已实测与 P3 色域无必然关系（本机 sRGB 模式下 screencap 像素零偏差），见下节。

## 色差适配（二期核心）

~~真机屏幕多为 Display P3 色域~~ → **实测已部分证伪**（2026-08-26，nubia PQ82A11）：`adb exec-out screencap -p` 输出的 PNG 不带 iCCP 嵌入配置，只有一个 sRGB 标记块（仅声明、非转换依据）；在设备当前色彩模式（`dumpsys SurfaceFlinger` 显示 `Current color mode: SRGB`，设备另支持 NATIVE/DISPLAY_P3）下，纯色网页 sRGB 像素经 SurfaceFlinger 合成后由 screencap 读回**完全原样**（#ff0000 → (255,0,0)，#8040c8 → (128,64,200)），帧缓冲即 sRGB，无需任何转换。

结论修正：色差**并非必然来自 P3 色域**。进一步实测（同日）：在系统设置切换屏幕色彩模式后，`Current color mode` 仍为 SRGB（仅 renderIntent 变化），sRGB 纯色读回依然零偏差——该机的色彩模式切换作用在面板级（帧缓冲之后），screencap 完全不受影响。也就是说至少在这台设备上，screencap 恒为 sRGB，与系统色彩模式无关。《运行错误》文档里 MatePad 上的色差 71/86 更可能来自该设备的厂商显示增强或其他环节，二期需要重新定位真凶。

游戏前台实测（同日，com.proximabeta.nikke）：游戏运行中 `Current color mode` 保持 SRGB，游戏 SurfaceView 图层 `dataspace=V0_SRGB`——游戏未请求广色域，screencap 在游戏内拿到的同样是 sRGB 像素。dumpsys 里的 `outputDataspace: DCI-P3` 是面板级输出管线（屏幕硬件原生 P3），发生在帧缓冲之后，不影响 screencap 读到的值。

- 若确认目标设备帧缓冲为 P3（dumpsys 当前模式为 DISPLAY_P3），再做 P3→sRGB 转换：参考实现见《NKAS_安卓本机兼容修改说明》文档 3.2 节（decode LUT → 线性变换矩阵 → encode LUT），建议注入点在 `module/device/adb/screenshot.py` 的 `screenshot()` 出口（`_handle_orientated_image` 之后），而非 droidcast.py 内，这样所有截图方法都受益。
- 残差校正矩阵不做硬编码（文档里的矩阵是 MatePad 单设备拟合值，无法泛化），做成配置项 + `dev_tools/` 校准脚本（真机与模拟器同页截图最小二乘拟合）。
- 兜底：允许真机模式放宽 `COLOR_SIMILAR_THRESHOLD`（`module/config/manual_config.py:94`，全局默认 10），作为校准仍不够时的 escape hatch。
- 注意 RGB565 只有 5/6/5 位精度，色域敏感场景可考虑真机默认走 PNG 路径。

## Android 15 截图失败（已解决）

《运行错误》文档：Android 15（含 MuMu Android 15 镜像）上 DroidCast `/screenshot` 与 `/preview` 均返回错误文本（"Failed to generate the screenshot..."）。

已落地的处理：截图方式显式可选——`Emulator.ScreenshotMethod` 增加 `ADB` 选项（`module/device/adb/method/adb.py` 的 `screenshot_adb`，`adb exec-out screencap -p`，PNG 全质量，约 1s/帧）。Android 15+ 真机选 ADB 即可；不做自动检测与回退，选 DroidCast 在不支持的设备上会按原错误链报错（日志含设备型号与系统版本的可读 payload）。已在 nubia PQ82A11（Android 15）真机验证通过。
