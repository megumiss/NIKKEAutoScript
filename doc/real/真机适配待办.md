# 真机适配待办

一期（PC 控真机最小闭环）已完成并在 nubia PQ82A11（Android 15）真机验证：

- `PhysicalDevice.Enable` 配置组（设置页与模拟器设置并列）。
- 启动时 `wm size 720x1280` + density 按宽度比例缩放（只改 size 不改 density 会让 UI 按原 dp 尺寸渲染、画面等比放大）；wm size 写入后显示管线生效有约 1s 延迟，已加启动等待；停止实例时自动 `wm size reset` + `wm density reset`（含 webui 侧 kill 兜底）。
- 截图：`Emulator.ScreenshotMethod` 增加 `ADB` 选项（`adb exec-out screencap`，PNG 全质量，约 1s/帧）。Android 15+ 上 DroidCast 被系统限制，选 ADB 即可；不做自动回退，选什么用什么。
- 控制：无 root 真机上 minitouch 被 SELinux 拦（/dev/input 对 shell 域不可读；atx-agent 同为 shell 域，0.10.0 不存在"ATX 桥接 minitouch"通道，已实测证伪）。控制方案由 `Emulator.ControlMethod` 显式选择，选什么用什么、不做自动回退。真机可选：`MaaTouch`（推荐，从 ALAS 移植，app_process 以 shell 身份注入输入事件，无需任何额外权限，支持流式滑动，nubia 实测通过）、`uiautomator2`（需在开发者选项开"USB 调试(安全设置)"）、`ADB`（input tap/swipe，零权限但每次一个 adb 进程，慢）。真机模式选 minitouch 会在启动时警告。MaaTouch/u2 通道点击精度均已实测验证。
- 坐标级操作的业务层入口统一为 `device.click_xy / long_click_xy / drag_xy`（`module/device/adb/control.py` 分发；win 端同名接口在 `module/device/win/automation.py`）。历史上的 `click_minitouch` 直调已全部改名。
- 连接失败不再尝试拉起模拟器。

## 真机使用硬性前提

- `wm size 720x1280` 必须生效——它是所有模板坐标与触控坐标的基础，不生效则截图硬校验直接拦截，这是设计意图而非 bug。
- 屏幕必须常亮（开发者选项"保持唤醒"），锁屏/AOD 下截图黑屏或停在锁屏，NKAS 不会解锁系统锁屏。
- 色差问题（P3 色域）仍存在，见下节。

## 色差适配（二期核心）

真机屏幕多为 Display P3 色域，NKAS 的模板与取色按 sRGB 制作，不经转换会出现大量识别失败（参见本目录《运行错误》文档：剧情活动奖励页按钮色差 71/86，阈值仅 5/10）。

- P3→sRGB 转换：参考实现见《NKAS_安卓本机兼容修改说明》文档 3.2 节（decode LUT → 线性变换矩阵 → encode LUT），建议注入点在 `module/device/adb/screenshot.py` 的 `screenshot()` 出口（`_handle_orientated_image` 之后），而非 droidcast.py 内，这样所有截图方法都受益。
- 残差校正矩阵不做硬编码（文档里的矩阵是 MatePad 单设备拟合值，无法泛化），做成配置项 + `dev_tools/` 校准脚本（真机与模拟器同页截图最小二乘拟合）。
- 兜底：允许真机模式放宽 `COLOR_SIMILAR_THRESHOLD`（`module/config/manual_config.py:94`，全局默认 10），作为校准仍不够时的 escape hatch。
- 注意 RGB565 只有 5/6/5 位精度，色域敏感场景可考虑真机默认走 PNG 路径。

## Android 15 截图失败（已解决）

《运行错误》文档：Android 15（含 MuMu Android 15 镜像）上 DroidCast `/screenshot` 与 `/preview` 均返回错误文本（"Failed to generate the screenshot..."）。

已落地的处理：截图方式显式可选——`Emulator.ScreenshotMethod` 增加 `ADB` 选项（`module/device/adb/method/adb.py` 的 `screenshot_adb`，`adb exec-out screencap -p`，PNG 全质量，约 1s/帧）。Android 15+ 真机选 ADB 即可；不做自动检测与回退，选 DroidCast 在不支持的设备上会按原错误链报错（日志含设备型号与系统版本的可读 payload）。已在 nubia PQ82A11（Android 15）真机验证通过。

## 分辨率硬校验

`module/device/adb/screenshot.py:61-65` 硬校验 720x1280。真机模式下分辨率由启动时的 `wm size 720x1280` 硬性保证（停止实例时自动恢复）。`wm size` 不生效属于不可运行状态，由该校验直接拦截报错，不做 resize 兜底——分辨率不对时跑下去也没有任何意义。
