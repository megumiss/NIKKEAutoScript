快速上手

三步开始自动化日常

下载并解压

从 Release 下载完整包，解压到纯英文路径，避免运行期编码问题。

启动 nkas.exe

双击运行 nkas.exe，等待自更新完成后自动打开 Web UI。

配置并运行

在设置中选择客户端与模拟器，勾选需要的任务，点击开始即可。详见 Wiki 安装指南。
