## 源码与错误回归

在真实 Git 对象与隔离工作区中验证：

- 全量快照、匹配基准增量、基准失配重请求完整快照。
- 新增 / 修改 / 删除文件及中文文件名；缺失父提交时维护 shallow，git log 和 fsck 可执行。
- 回滚旧 HEAD、引用与工作区后 fsck 仍通过；保留已导入快照必要的浅边界。
- tracked 修改、未跟踪文件冲突、下载期间 HEAD 改变均被保护。
- 自定义 HTTPS、SSH、HTTP 仓库地址不影响 Mirror 检查；请求固定源码 RID，检查不修改 HEAD。
- 更新中断与未确认启动可恢复旧源码；成功启动清除事务记录；更新后新增用户修改时拒绝破坏性恢复。
- 实际 Python 3.9 拒绝需要 Python 3.10 的目标语法，引用与 HEAD 保持不变。
- 使用官方 Python / pip 和本地测试 wheel，真实验证包从 0.1 升级 0.2，再按依赖快照恢复 0.1。
- 作者时间与提交者时间不同、时区不同仍得到正确 UTC committer 版本；源码允许旧时间戳的官方回退。
- 校验失败、超出下载大小、损坏 ZIP、重复 / 越界 / 链接条目、缺少目标对象均拒绝安装。
- 无 CDK、业务错误、未知错误、非法 JSON / 业务码、网络错误与下载 JSON 错误码不会被判定为最新。
- 7001–7005、8001、8009 等错误映射，以及请求异常中的凭据脱敏。

## 启动器回归

独立验证器直接编译生产 Rust 模块，仅调整测试安装的当前版本以模拟旧客户端，不改变项目版本。

- 同版、本地更高版本、预发布版不触发降级；更高 SemVer 可更新。
- 无 CDK 检查不依赖 url / filesize / sha256；有效 / 错误 CDK 经真实 Rust API 适配器处理。
- 下载大小与 SHA-256 拒绝逻辑；安装或启动失败恢复原 EXE。
- Python 锁拒绝 Rust 更新，Rust 锁拒绝 Python 更新，进程退出后可重新获取。
- Rust 更新持锁时，实际部署 API 的更新源修改与部署重置返回 409。

## 页面与隐私

使用官方运行包中 Python 3.9.13 / Starlette 0.26.1 启动完整隔离 Web UI，Playwright 验证：

- 部署页来源选择保存、密码输入框、CDK 保存 / schema 掩码、YAML 不包含 CDK。
- 无 CDK 显示更新可用与配置提示；实际 POST 更新返回 422，不先中断任务。
- 有效 CDK 显示应用入口；过期、类型错误、下载上限与实际无效样例显示正确失败提示。
- 更新确认后实际后端保护本地源码修改，返回应用失败并提供重试，隔离仓库 HEAD 不变。
- 普通浏览器的启动器操作保持禁用；Mirror 展示本地 Git 记录，不冒充服务端完整历史。
- 应用日志扫描未发现测试密钥；页面无 JavaScript 异常。发布说明按文本渲染。

## 更新页与 CDK 输入交互

- 更新页只保留源码、启动器与有内容的更新记录，不新增 Mirror 宣传卡或部署快捷按钮。
- Mirror 返回的源码 / 启动器说明统一放入更新记录，沿用提交行样式；无内容时显示空状态。
- CDK 输入不带清除按钮，清空输入并保存即可删除；密码掩码与存储方式不变。
- 构建通过；实际页面验证按钮已移除、清空 CDK 生效、无记录 / 有记录及窄屏布局，无 JavaScript 异常。
- Mirror 源码说明以提交说明和 SHA 显示在更新记录；已在 Git 历史中的提交去重，当前版本标记保留。
- 不含 SHA 的说明显示服务端版本号，启动器记录显示 EXE 版本；说明按纯文本渲染，无单独展开区域。
